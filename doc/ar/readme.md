# إضافة PowerBox لقارئ الشاشة NVDA

[English](../en/readme.md) | [العربية](readme.md)

**المطور:** توماس أ. فايز (Thomas A. Fayez)  
**الإصدار:** 2.0.2  

تُعد **PowerBox** إضافة إنتاجية وإدارية مؤسسية فائقة الأداء مصممة لتوفير السرعة والراحة والتحكم العميق في النظام. توفر الإضافة اختصارات مريحة لـ NVDA للتحكم في صوت النظام الرئيسي وصوت التطبيقات المستقلة، ومحاكاة النقر الذكي للماوس مع التوجيه التلقائي للمؤشر، وتشغيل فوري للطرفيات في المجلد المفتوح حالياً، وتقدم **طبقات الاختصارات (Gesture Layers)** النظيفة لتشغيل التطبيقات السريعة، وفحص الشبكة المحلية المتقدم مع فاحص أجهزة LAN الميسر، والتحليل اللحظي لمقابس واتصالات الشبكة والأمان، وإدارة الملفات والتخزين مع فحص الملفات المقفولة، وتجميد البرامج بالنواة، وإدارة متكاملة لطاقة النظام مع مؤقت نوم ذكي.

## ✨ مفهوم "الطبقات" (The Concept of "Layers")
لتجنب تعارض الاختصارات، وحركات الأصابع المعقدة، والتركيبات المربكة للضغط على عدة مفاتيح معاً، تعتمد PowerBox على معمارية "الطبقات" النظيفة. تضغط اختصاراً بادئاً واحداً لتفعيل الطبقة المطلوبة، يليه مفتاح واحد فقط لتنفيذ الإجراء. 
*الضغط على حرف `H` داخل أي طبقة نشطة يفتح حوار مساعدة سياقي ميسر يعرض لك كافة المفاتيح المتاحة.*

**التنبيهات الذكية للدخول في الطبقات:** تحترم الإضافة بدقة نمط التغذية الراجعة المحدد في الإعدادات:
* **نغمات ونطق معاً (Beep and speak):** تصدر نغمة مميزة للطبقة وينطق اسمها فوراً (مثل: *"طبقة النظام"*, *"طبقة الملفات"*, *"طبقة الشبكات"*).
* **نطق فقط (Speech only):** ينطق اسم الطبقة بوضوح تام دون أي نغمات بيب.
* **نغمات بيب فقط (Beep only):** يكتفي بإصدار نغمة التعريف السريعة الخاصة بالطبقة فقط.
* **صامت (None):** تشغيل صامت بالكامل؛ تدخل في الطبقة بصمت تام دون مقاطعتك.
* *الضغط على مفتاح غير مخصص داخل أي طبقة يحترم أيضاً نمط التغذية الراجعة لديك (ينطق "مفتاح غير صالح"، أو يصدر نغمة خطأ منخفضة، أو يخرج بصمت).*

## ⌨️ الاختصارات العامة (Global Shortcuts)

### 🔊 صوت النظام الرئيسي (Master System Audio)
* **NVDA + Win + السهم لأعلى / لأسفل:** رفع / خفض مستوى الصوت الرئيسي *(ينطق المستوى بدقة، مثال: مستوى الصوت: 50%)*.
* **NVDA + Win + M:** تبديل كتم الصوت الرئيسي *(كتم عتادي فوري على مستوى النواة مع إعلان صوتي صريح "تم الكتم" / "تم إلغاء الكتم")*.

### 🎧 صوت التطبيق النشط (متحكم التطبيقات المستقلة)
ضبط مستوى صوت البرنامج المفتوح والمركز عليه حالياً (مثل Firefox, Zoom, Spotify, VLC) دون التأثير على صوت الناطق NVDA أو الصوت العام للنظام!
* **NVDA + Win + Shift + السهم لأعلى:** رفع صوت التطبيق النشط بمقدار 5% *(ينطق اسم التطبيق ومستوى صوته، مثال: Firefox: 45%)*.
* **NVDA + Win + Shift + السهم لأسفل:** خفض صوت التطبيق النشط بمقدار 5% *(ينطق اسم التطبيق ومستوى صوته، مثال: Firefox: 35%)*.
* **NVDA + Win + Shift + M:** كتم / إلغاء كتم صوت التطبيق النشط فقط *(يكتم التطبيق النشط دون إسكات NVDA أو أصوات النظام الأخرى)*.

### وسائط التشغيل والتنقل في المتصفح
* **NVDA + Win + P:** تشغيل / إيقاف مؤقت للوسائط.
* **NVDA + Win + السهم الأيمن / الأيسر:** المقطع التالي / المقطع السابق.
* **NVDA + Win + Backspace:** رجوع للصفحة السابقة في المتصفح.
* **NVDA + Win + Enter:** تقدم للصفحة التالية في المتصفح.
* **NVDA + Win + R:** تحديث صفحة المتصفح.

### 🖱️ محاكاة الماوس الذكية وقوائم السياق
**المشكلة:** هل واجهت في أي وقت زراً غير ميسر أو عنصراً مخصصاً (مثل معالجات التثبيت في برامج كـ Foxit Reader أو تطبيقات الويب المخصصة) يقرأه NVDA عبر استعراض الكائنات، ولكن الضغط على `Enter` أو `المسافة` لا يفعل أي شيء على الإطلاق؟

**الحل:** ميزة النقر الذكي في PowerBox تحل هذا الأمر فورياً؛ حيث تقوم بحساب المركز الهندسي الدقيق لكائن ملاح NVDA، وتوجه مؤشر الفأرة الحقيقي لنظام Windows مباشرة إلى تلك الإحداثيات، وتنفذ نقرة عتادية أصلية.

**كيفية الاستخدام:**
1. انتقل إلى العنصر غير المستجيب باستخدام استعراض الكائنات في NVDA (مثل `NVDA + 4 / 6 على لوحة الأرقام` للحاسوب المكتبي، أو `NVDA + Shift + السهم الأيسر / الأيمن` للحاسوب المحمول).
2. اضغط **NVDA + Win + C** لتنفيذ نقرة ماوس يسرى ذكية على مركز الكائن.

* **NVDA + Win + C:** نقر أيسر ذكي بالماوس.
* **NVDA + Win + X:** نقر أيمن ذكي بالماوس.
* **NVDA + Win + Z:** نقر مزدوج ذكي بالماوس.
* **NVDA + Win + A:** قائمة التطبيقات *(قائمة السياق الحديثة لنظام Windows 11)*.
* **NVDA + Win + Shift + A:** قائمة السياق الكلاسيكية *(لتجاوز قيود ويندوز 11 وفتح قائمة السياق الكلاسيكية الكاملة مع خيارات 7-Zip و WinRAR وغيرها)*.

### 📡 اختصارات الشبكة السريعة
* **NVDA + Win + I:** نطق عنوان IP المحلي *(اضغط مرتين سريعاً لنسخه إلى الحافظة)*.
* **NVDA + Win + Shift + I:** نطق عنوان IP العام *(اضغط مرتين سريعاً لنسخه إلى الحافظة)*.

### ❓ المساعدة العامة
* **NVDA + Win + H:** عرض نافذة المساعدة العامة لـ PowerBox التي تسرد جميع الاختصارات والطبقات الحالية.

## ⚡ طبقة النظام وإدارة الطاقة الذكية (Smart System & Power Layer)
**الاختصار البادئ:** `NVDA + Win + S`

توفر تحكماً مركزياً وميسراً ومحمياً من الأخطاء العرضية في طاقة النظام، وفحص موارد العمليات اللحظي، وإنعاش المستكشف، وإدارة جلسات خوادم Windows Server بالكامل. اضغط الاختصار البادئ أعلاه متبوعاً بأحد المفاتيح:
* **T:** **تعيين مؤقت إيقاف التشغيل:** يفتح حوار إعداد ميسر لجدولة إيقاف تشغيل الكمبيوتر تلقائياً. اختر من الإعدادات المسبقة السريعة (15د، 30د، 45د، 60د) أو أدخل مدة مخصصة بالدقائق.
* **Shift + T:** **الاستعلام عن حالة المؤقت:** ينطق الوقت الدقيق المتبقي (بالدقائق والثواني) قبل إيقاف التشغيل المجدول.
* **C:** **إلغاء المؤقت:** يلغي أي مؤقت إيقاف تشغيل نشط فوراً.
* **D:** **إيقاف تشغيل الكمبيوتر:** يبدأ إيقاف تشغيل منظم للنظام مع تأكيد الأمان الذي يختاره المستخدم.
* **R:** **إعادة تشغيل الكمبيوتر:** يبدأ إعادة تشغيل النظام مع تأكيد الأمان.
* **S:** **وضع السكون:** يضع الكمبيوتر في وضع الاستعداد منخفض الطاقة.
* **B:** **وضع الإسبات:** يحفظ حالة الذاكرة على القرص ويوقف تشغيل الجهاز.
* **L:** **قفل محطة العمل:** يقفل سطح مكتب Windows فوراً.
* **P:** **فحص موارد التطبيق النشط:** ينطق فوراً استهلاك الذاكرة الفعلية الحية (Working Set) ونسبة استخدام المعالج (CPU%) للتطبيق النشط المركز عليه.
* **Shift + P:** **نسخ ونطق إحصاءات التطبيق النشط:** ينسخ استهلاك المعالج والرام للتطبيق النشط مباشرة إلى الحافظة وينطقهما.
* **Control + P:** **منصة إدارة عمليات وجلسات الخادم (Server Process Hub):** يفتح لوحة التحكم الإدارية للمؤسسات. يعرض حالة نبض الخادم، واستهلاك الـ CPU والـ RAM المباشر مجمعاً حسب التطبيق، وتفاصيل المستخدمين، وعناوين النوافذ المتوافقة مع العربية، ووقت تشغيل العمليات، ومعمارية النظام، وإدارة كاملة للجلسات (تسجيل خروج، قطع اتصال، إنهاء العمليات، وتجميد البرامج بالنواة).
* **Control + E:** **إنعاش وتشغيل مستكشف Windows الذكي:** ينعش بذكاء غلاف مستكشف Windows المنهار/الميت أو يعيد تشغيل شريط المهام المتجمد في ثوانٍ دون الحاجة لإعادة تشغيل الحاسوب.
* **H:** عرض مساعدة طبقة النظام.

### 🖥️ منصة إدارة عمليات وجلسات الخادم (Server Process Hub & Enterprise Session Manager)
بالضغط على **NVDA + Win + S** متبوعاً بـ **Control + P**، تنطلق لوحة تحكم إدارية ميسرة وعالية الأداء مبنية على واجهات ويندوز الرسمية (`wtsapi32.dll`). تراقب المنصة ديناميكياً تطبيقات المستخدمين، واستهلاك الموارد عبر الجلسات المتعددة، وجلسات سطح المكتب البعيد النشطة عبر محطات عمل Windows 10/11 وبيئات Windows Server (RDSH / RemoteApp).

#### مميزات الحوار والتنقل في المنصة:
* **نبض الخادم اللحظي:** يعرض الحالة العامة للخادم (الجلسات النشطة مقابل المنقطعة، إجمالي عدد تطبيقات المستخدمين، والرام التراكمي الإجمالي).
* **الفلترة اللحظية الفورية (`Alt + F`):** تصفية التطبيقات فوراً بمجرد الكتابة دون فقدان تركيز لوحة المفاتيح. اضغط **سهم لأسفل** للانتقال مباشرة إلى النتائج المفلترة.
* **Enter / Alt + V:** **الدخول لتفاصيل المستخدمين:** فحص المستخدمين وجلسات سطح المكتب البعيد المحددة التي تشغل التطبيق المختار، إلى جانب استهلاك الرام وحالة الجلسة لكل موظف.
* **Alt + T:** **خصائص التطبيق التفصيلية:** يفتح عارض نصوص ميسر بالكامل وقابل للتمرير يعرض استهلاك المعالج الحي المعاد حسابه، ومسار الملف التنفيذي، ومعمارية البرنامج (64 بت / 32 بت)، ومدة وقت تشغيل العملية، وعناوين النوافذ والتبويبات المفتوحة باللغة العربية.
* **F6 / Alt + S:** **تبديل لوحة جميع الجلسات:** التبديل الفوري بين نظرة عامة على التطبيقات وبين مدير جميع جلسات الخادم العامة. في شاشة الجلسات، يمكن للمديرين مراقبة أسماء أجهزة الحواسيب المتصلة وعناوين الـ IP الخاصة بها (مثال: `CLIENT-PC (10.10.x.x)`)، وحالات الجلسات، وإجمالي الرام المستهلك لكل جلسة.
* **Backspace / Alt + B:** الرجوع إلى قائمة التطبيقات الرئيسية من شاشة تفاصيل المستخدمين.
* **Alt + E:** **إنهاء التطبيق / العملية:** إنهاء التطبيق بأمان عبر كافة المستخدمين أو للمستخدم المحدد فقط، مع حوارات تأكيد الأمان.
* **Alt + L / Alt + D:** **تسجيل الخروج أو قطع الجلسات:** قطع الاتصال فوراً أو تسجيل خروج الجلسات الخاملة/المنقطعة المعلقة مباشرة من اللوحة.
* **نسخ التقرير (`Alt + R`):** ينسخ ملخصاً تشخيصياً منسقاً ونظيفاً إلى الحافظة.
* **F5:** تحديث تزامني لكافة مقاييس ومؤشرات الخادم في الخلفية.
* **Escape / Alt + C:** إغلاق لوحة التحكم.

#### 🎛️ أوامر قائمة السياق (`Shift + F10` أو `مفتاح التطبيقات Applications Key`):
اضغط `Shift + F10` على أي سطر تطبيق أو مستخدم للوصول إلى إجراءات إدارية متقدمة:
* **تجميد التطبيق / العملية (Suspend / Freeze):** يعتمد على دوال النواة العميقة لويندوز (`ntdll.dll: NtSuspendProcess`) لتجميد كافة خيوط المعالجة للتطبيق فوراً، مما يخفض استهلاكه للمعالج إلى 0% ويوفر طاقة البطارية ويبرد الجهاز دون إغلاق البرنامج أو فقدان العمل غير المحفوظ.
* **استئناف التطبيق / العملية (Resume):** يستأنف خيوط المعالجة المجمدة فوراً (`NtResumeProcess`)، مما يسمح للبرنامج بمواصلة العمل بسلاسة من نفس النقطة.
* **تتبع اتصالات الشبكة... (Track Network Connections):** يشغل منصة **شبكات الخادم المؤسسية** المخصصة (`server_network_hub.py`) للتطبيق أو المستخدم المحدد، كاشفاً جميع اتصالات السيرفرات الحية، وعناوين IP الأجهزة المتصلة، وحالات المقابس مع نسبتها لمستخدميها.
* **إنهاء التطبيق / العملية:** إنهاء المهام المعلقة مع التحقق الأمني.
* **نسخ التفاصيل / الملخص:** تصدير بيانات السطر المحدد سريعاً إلى الحافظة.

#### 🌐 منصة شبكات الخادم المؤسسية (`server_network_hub.py`):
عند تشغيلها من قائمة سياق منصة السيرفر (`Shift + F10` -> `Track Network Connections...`)، تفتح لوحة تحكم مخصصة لشبكات بيئات العمل متعددة المستخدمين:
* **صندوق فلترة المستخدمين المنسدل (`Alt + U`):** في بيئات السيرفرات، يستطيع المديرون عرض مقابس الشبكة عبر كامل الخادم (`All Users`)، أو تبديل القائمة المنسدلة إلى أي موظف محدد في الدومين (مثال: `AD\thomas`) لعزل وتدقيق النشاط الشبكي لذلك الموظف في الوقت الفعلي.
* **عمود نسبة المستخدم والجلسة:** يعرض كل اتصال مقبس حساب الدومين الدقيق ومعرف الجلسة المالك له (مثال: `AD\thomas (S:38)`). في محطات العمل الفردية العادية، يختفي هذا العمود وصندوق الفلترة تلقائياً لتوفير البساطة التامة.
* **ثلاثة تبويبات مخصصة لحركة المرور:**
  * **🌐 تبويب اتصالات الإنترنت:** يعرض خوادم السحاب والويب الخارجية الحقيقية.
  * **🏠 تبويب الشبكة المحلية (LAN):** يتتبع حركة المرور إلى الراوترات المحلية، والطابعات، وخوادم الدومين الداخلية (`192.168.x.x`, `10.x.x.x`).
  * **💻 تبويب Localhost / المنافذ المستمعة:** يفحص قنوات الـ IPC الداخلية (`127.0.0.1`) ومنافذ خوادم التطوير المحلية المستمعة (`0.0.0.0:8000`, `3000`).
* **أدوات التحكم والعمليات المؤسسية:**
  * **Alt + T:** **قياس واختبار زمن استجابة المنفذ (Latency):** الضغط العادي على `Alt + T` (أو `المسافة` / `Enter`) ينطق حالة الاتصال وزمن الـ Ping بالمللي ثانية. **الضغط مع الاستمرار على Shift (مثل `Shift + Space` أو `Shift + Enter`) ينسخ نتيجة الفحص إلى الحافظة وينطقها معاً في إجراء واحد نظيف.**
  * **Alt + D:** **قطع الاتصال الفردي (`SetTcpEntry`):** ينهي فوراً مقبس TCP نشط محدد دون إغلاق التطبيق ودون التأثير على المستخدمين الآخرين.
  * **Alt + I:** مسح سجل الاتصالات المغلقة/غير النشطة.
  * **Alt + V:** فحص السمعة الأمنية للآي بي عبر موقع VirusTotal في المتصفح.
  * **Alt + O:** فتح عنوان السيرفر البعيد مباشرة في المتصفح الافتراضي.
  * **Alt + E:** زر الطوارئ لإنهاء التطبيق عبر كافة معرفات عملياته (PIDs).

#### 💡 فلسفة التصميم: الفلترة الذكية للضوضاء والنطاق المؤسسي
على عكس مدير مهام Windows التقليدي—الذي يرهق مستخدمي قارئات الشاشة بأكثر من 150 عملية نظام خدمية غير تفاعلية وحاويات تعريفات صامتة (مثل `svchost.exe` ومساعدات التعريفات)—تتبنى PowerBox عمداً **فلسفة خالية من الضوضاء ومتمحورة حول التطبيقات**:
* **الفلترة الذكية القائمة على القواعد:** تقوم اللوحة تلقائياً باستبعاد مهام مكونات ويندوز 11 الداخلية (مثل `SystemApps`)، وحاويات خدمات التعريفات، وعمليات `SYSTEM` غير التفاعلية. هذا يوفر رؤية عالية الإشارة مخصصة حصراً لـ **التطبيقات الحقيقية للمستخدمين** وأطر العمل الخلفية الثقيلة (مثل المتصفحات متعددة العمليات، وحاويات Edge WebView2، وبيئات تطوير البرمجيات).
* **الأمان القائم على الأدوار وحدود الصلاحيات:**
  * **عند التشغيل كمسؤول (Administrator):** تفتح الإضافة قدرات إدارية كاملة عبر كامل السيرفر—مما يتيح للمديرين مراقبة كافة مستخدمي الدومين (`DOMAIN\User`)، وتجميع مئات العمليات الموزعة (مثل جمع 100+ عملية إيدج عبر الجلسات)، واكتشاف تسريبات ذاكرة الجلسات المعلقة، وإنهاء العمليات أو تسجيل خروج المستخدمين البعيدين.
  * **عند التشغيل كمستخدم عادي (Standard User):** تحترم الإضافة حدود أمان نظام Windows بسلاسة دون أخطاء؛ حيث يمتلك المستخدمون تحكماً كاملاً في تطبيقاتهم وجلستهم المحلية الخاصة، بينما تظل التعديلات عبر الجلسات للزملاء الآخرين مقيدة بأمان.
* **حسابات المستخدمين وحل أجهزة العملاء المتصلة:** تُعرض الحسابات باستخدام معايير تسمية الأمان الرسمية لويندوز (`DOMAIN\User` في بيئات Active Directory أو `COMPUTER\User` في محطات العمل الفردية). وتعرض شاشة الجلسات (`F6`) صراحة اسم حاسوب العميل الفعلي وعنوان الآي بي الذي يتصل منه (مثال: `MACHINE-NAME (192.168.x.x)`)، مما يوفر شفافية شبكية لا تقدر بثمن.
* **سلوك عناوين النوافذ (العزل المحلي مقابل RemoteApp):** يتم التقاط عناوين النوافذ والتبويبات التفاعلية (بما في ذلك النصوص العربية الكاملة) عند فحص التطبيقات داخل جلسة المستخدم النشطة الحالية. وفي بيئات السيرفر البعيدة متعددة المستخدمين (RDS / RemoteApp)، تفرض نواة ويندوز عمداً عزلاً أمنياً بين أسطح مكتب الجلسات لمنع التجسس على نوافذ الآخرين.
* **الأمان بالتصميم (حماية قارئ الشاشة):** مكونات بنية ويندوز الحيوية وعمليات NVDA الداخلية (مثل `nvda.exe` و `nvda_synthDriverHost.exe`) محمية ومستبعدة عمداً من إجراءات الإنهاء لمنع فقدان صوت آلة النطق أو إغلاق النظام بالخطأ.

### 🛡️ الحماية من إيقاف التشغيل العرضي
لمنع فقدان البيانات، تدعم PowerBox نمطين قابلين للتخصيص لتأكيد أوامر الطاقة في الإعدادات:
1. **حوار التأكيد (الافتراضي والموصى به):** يظهر حواراً ميسراً يطلب التأكيد، مع وضع التركيز الافتراضي عمداً على زر **[لا / No]** لمنع الضغط بالخطأ على Enter.
2. **التأكيد بالضغط المزدوج:** يتطلب الضغط على حرف `D` أو `R` مرتين خلال ثانيتين. وإذا غيرت رأيك ولم تضغط المفتاح مجدداً، تقوم PowerBox تلقائياً بإنهاء الطبقة وإعادة لوحة المفاتيح لوضعها الطبيعي بعد ثانيتين.

*بالإضافة إلى ذلك، عندما يصل مؤقت إيقاف التشغيل إلى 60 ثانية متبقية، تصدر PowerBox نغمة تنبيه مزدوجة مميزة وتنطق تحذيراً صريحاً، مما يمنحك وقتاً للإلغاء إذا كنت لا تزال تعمل.*

## 📁 طبقة الملفات والتخزين الذكية (Smart Files & Storage Layer)
**الاختصار البادئ:** `NVDA + Win + F`

تشخيص شامل للملفات، ونبض التخزين اللحظي، والتحقق من البصمات، وإدارة الملفات المقفولة. اضغط الاختصار البادئ أعلاه متبوعاً بأحد المفاتيح:
* **S:** **حساب حجم العنصر الذكي:** حاسب حجم واعٍ بالسياق:
  * **الملف المحدد:** ينطق حجم الملف الفيزيائي فوراً.
  * **المجلد المحدد:** يحسب الحجم الحقيقي التراكمي للمجلد، وعدد الملفات، وعدد المجلدات الفرعية في الخلفية مع نبض صوتي متتابع أثناء الحساب. الضغط على `S` مجدداً يلغي الحساب فوراً.
  * **القرص المحدد أو مساحة فارغة في المجلد:** ينطق فوراً مقاييس القسم كاملة (المساحة الحرة، ونسبة المتبقي، والمساحة المستخدمة، والسعة الإجمالية للقرص).
* **Shift + S:** **نسخ حجم العنصر:** ينسخ مقاييس الحجم المنسقة إلى الحافظة وينطقها.
* **D:** **نبض مساحة الأقراص:** ينطق السعة الإجمالية، والمساحة المستخدمة، والمساحة الحرة، ونسبة المتبقي عبر **جميع** الأقراص المحلية والخارجية (C:, D:, E:)، مع تنبيهات عند انخفاض المساحة (< 15%).
* **Shift + D:** **نسخ تقرير الأقراص:** ينسخ تقرير التخزين متعدد الأقراص كاملاً إلى الحافظة وينطقه.
* **L:** **كاشف أقفال الملفات (Who Locks This File?):** يعتمد على واجهة مايكروسوفت الرسمية (`rstrtmgr.dll - Restart Manager API`) لاكتشاف التطبيقات أو الخدمات التي تحتكر الملف أو المجلد المحدد وتمنع حذفه. وإذا كان مقفولاً، يفتح حواراً ميسراً لإنهاء العمليات المحتكرة وتحرير الملف فوراً!
* **Shift + L:** **نسخ تفاصيل الأقفال:** ينسخ أسماء التطبيقات المحتكرة للملف ومعرفات عمليتها (PIDs) مباشرة إلى الحافظة.
* **C:** **حساب البصمة ومطابقتها (Checksum):** يحسب بصمة التجزئة المشفرة (SHA-256 أو MD5 أو SHA-1 بناءً على الإعدادات) للملف المحدد. **يقارن تلقائياً مع الحافظة:** إذا تم نسخ بصمة مسبقاً، يعلن فوراً عن التحقق بنطق `HASH MATCH!` عند التطابق أو `HASH MISMATCH!` عند الاختلاف.
* **Shift + C:** **نسخ البصمة:** ينسخ بصمة الملف المحسوبة مباشرة إلى الحافظة.
* **N:** **إنشاء ملف فوري (Touch):** يظهر حواراً ميسراً يعرض مسار المجلد الوجهة لإنشاء ملف فارغ فوراً (مثل `notes.txt`, `script.py`) في 0.01 ثانية دون المرور بقوائم ويندوز البطيئة.
* **P:** **نسخ مسار Windows:** ينسخ المسار الكامل للعنصر المحدد أو المجلد الحالي. يحل تلقائياً اختصارات سطح المكتب (`.lnk`) لمسار ملفها التنفيذي أو مجلدها الأصلي الفعلي المستهدف!
* **Shift + P:** **نسخ مسار WSL Linux:** يحول وينسخ المسار المحدد إلى صيغة نظام لينكس في WSL (مثال: `/mnt/c/Projects/app.py`).
* **H:** عرض مساعدة طبقة الملفات.

## 🌐 طبقة الشبكات الذكية (Smart Network Layer)
**الاختصار البادئ:** `NVDA + Win + N`

أدوات موحدة لتشخيص الشبكة، وتدقيق الأجهزة، وتتبع مقابس الاتصالات الحية. اضغط الاختصار البادئ أعلاه متبوعاً بأحد المفاتيح:
* **S:** **فحص الشبكة المحلية:** يشغل ماسح الشبكة المحلية عالي السرعة (2-3 ثوانٍ) دون تجميد النظام، مع إصدار نبض صوتي أثناء الفحص. الضغط على `NVDA + Win + N` ثم `S` مجدداً أثناء الفحص يلغيه فوراً.
* **C:** **تتبع اتصالات التطبيق النشط:** يفتح مراقب مقابس الشبكة والأمان اللحظي ذو التبويبات الثلاثة للتطبيق المركز عليه حالياً.
* **L:** نطق IP المحلي.
* **Shift + L:** نسخ ونطق IP المحلي.
* **P:** نطق IP العام.
* **Shift + P:** نسخ ونطق IP العام.
* **G:** نطق البوابة الافتراضية (عنوان الراوتر).
* **Shift + G:** نسخ ونطق البوابة الافتراضية (عنوان الراوتر).
* **H:** عرض مساعدة طبقة الشبكات.

### 🌐 مراقب اتصالات الشبكة اللحظي للتطبيقات (`process_network_tracker.py`)
بالضغط على **NVDA + Win + N** متبوعاً بـ **C**، تنطلق لوحة تحليل أمني ومراقبة حية للمقابس النشطة للتطبيق المفتوح حالياً. بنيت الأداة على واجهات IP Helper الرسمية (`GetExtendedTcpTable`, `GetExtendedUdpTable`)، وتفصل حركة المرور في ثلاثة تبويبات مخصصة دون سرقة للتركيز:
* **🌐 تبويب اتصالات الإنترنت:** يعرض خوادم الويب والسحاب الخارجية الحقيقية (Google, WhatsApp, CDNs, Fastly).
* **🏠 تبويب الشبكة المحلية (LAN):** يتتبع الاتصالات بالراوترات المحلية، الطابعات، أو خوادم الدومين الداخلية (`192.168.x.x`, `10.x.x.x`).
* **💻 تبويب Localhost / المنافذ المستمعة:** يفحص قنوات الـ IPC الداخلية (`127.0.0.1`) ومنافذ التطوير المحلية المستمعة (`0.0.0.0:8000`, `3000`) معزولة تماماً عن حركة الإنترنت.

#### المميزات والقدرات الخارقة:
* **تحديث حي دون مقاطعة:** يتحدث الجدول في مكانه كل 2.5 ثانية دون إعادة تعيين التركيز، ودون مسح القائمة، ودون قطع صوت الناطق NVDA.
* **الاحتفاظ بالاتصالات المغلقة (`Closed`):** تظل الاتصالات اللحظية العابرة مرئية في السجل حتى لا تفوتك رسائل الـ Ping أو التنبيهات السريعة. اضغط **Alt + I** (`مسح غير النشط Clear Inactive`) لتنظيف السجل والبدء من جديد.
* **Alt + T:** **فحص سريع للمنفذ وزمن الاستجابة (0.2 ثانية):** يفحص زمن استجابة المنفذ بالمللي ثانية مباشرة دون فتح أي نوافذ منبثقة.
  * **الضغط العادي (`المسافة`, `Enter`, أو `Alt + T`):** ينطق حالة الاتصال وزمن استجابة الـ Ping.
  * **الضغط مع Shift أثناء التفعيل (`Shift + Space`, `Shift + Enter`):** ينسخ نتيجة الفحص وزمن الاستجابة إلى الحافظة وينطقها معاً في إجراء واحد نظيف.
* **Alt + D:** **قطع الاتصال الفردي:** ينهي فوراً مقبس TCP نشط محدد باستخدام دالة النواة `SetTcpEntry(MIB_TCP_STATE_DELETE_TCB)` دون إغلاق التطبيق.
* **Alt + V:** **فحص التهديدات عبر VirusTotal:** يفتح تقارير السمعة الأمنية الفورية لعناوين IP العامة في المتصفح.
* **Alt + O:** **فتح في المتصفح:** يفتح عناوين خوادم الويب مباشرة في متصفح الإنترنت الافتراضي.
* **Alt + E:** **إنهاء التطبيق للطوارئ:** زر طوارئ لإنهاء التطبيق عبر كافة معرفات عملياته (PIDs) إذا تم اكتشاف نشاط خبيث أو مريب.
* **قائمة السياق (`Shift + F10`):** توفر إجراءات ميسرة مباشرة تشمل خيارات منفصلة لـ `فحص المنفذ وقياس زمن الاستجابة` و `فحص المنفذ ونسخ النتيجة`.

### مميزات حوار فاحص الشبكة المحلية (Network Scanner)
عند اكتمال فحص الشبكة، يعرض حوار ميسر ومتمركز كافة الأجهزة المكتشفة:
* **Enter / Alt + I:** نسخ عنوان IP للجهاز المحدد.
* **Alt + M:** نسخ عنوان MAC.
* **Alt + O:** **فتح في متصفح الويب:** يفحص تزامناً منافذ الويب الشائعة (80, 443, 8080, 8443) في ~200 مللي ثانية ويفتح صفحة إدارة الجهاز (مثل لوحة تحكم الراوتر أو الطابعة الذكية).
* **Alt + R:** إعادة فحص الشبكة مباشرة من الحوار.
* **Alt + A:** نسخ كافة التفاصيل (IP, الاسم, المصنع, MAC) كسطر نصي منسق.
* **Alt + C / Escape:** إغلاق الحوار.
* *يميز بذكاء أجهزة **(This PC)**، و **Router / Default Gateway**، والأجهزة المحمولة التي تستخدم عناوين MAC عشوائية خاصة (IEEE 802 LAA).*

### 📱 ملاحظة حول الهواتف الذكية وتوفير طاقة الواي فاي
تطبق أنظمة تشغيل الهواتف الحديثة (Android و iOS) آليات صارمة لتوفير طاقة الواي فاي (وضع Doze / سكون DTIM). عندما تكون شاشة الهاتف مقفلة أو خاملة، تنام شريحة الواي فاي بين دفقات الحزم وتتجاهل طلبات ARP المرسلة من حاسوبك، مما يجعل الهاتف يبدو أحياناً غير مستجيب أثناء الفحص. مجرد إيقاظ شاشة الهاتف أو فتح قفلها يجعله قابلاً للاكتشاف فوراً.

بالإضافة إلى ذلك، تفعل الهواتف الذكية الحديثة **عنوان Wi-Fi الخاص (MAC Randomization)** افتراضياً لحماية الخصوصية. تكتشف PowerBox رياضياً هذه العناوين عبر معايير IEEE 802 وتصنفها بوضوح كـ `Randomized MAC (Phone / Mobile)`.

* **H:** عرض مساعدة التطبيقات السريعة.

## 💻 طبقة الطرفيات الذكية (Smart Terminal Layer)
**الاختصار البادئ:** `NVDA + Win + T`

تفتح جميع الطرفيات موجهة مباشرة إلى **مسار المجلد أو اللسان المفتوح حالياً في مستكشف Windows (بما في ذلك ألسنة Windows 11)**! اضغط الاختصار البادئ أعلاه متبوعاً بأحد المفاتيح:
* **P:** فتح PowerShell في المجلد الحالي.
* **Shift + P:** فتح PowerShell كمسؤول في المجلد الحالي.
* **C:** فتح موجه الأوامر (CMD) في المجلد الحالي.
* **Shift + C:** فتح موجه الأوامر كمسؤول في المجلد الحالي.
* **W:** فتح بيئة WSL (نظام ويندوز الفرعي للينكس) في المجلد الحالي.
* **H:** عرض مساعدة طبقة الطرفيات.

## ⚙️ إعدادات الإضافة وتفضيلاتها (Settings Configuration)
قم بتخصيص تفضيلات PowerBox من **قائمة NVDA -> تفضيلات -> الإعدادات -> PowerBox**:
* **نمط التغذية الراجعة للأوامر (Action feedback mode):** اختر بين *بدون تنبيهات (صامت)*، *نغمات بيب فقط*، *نطق اسم الإجراء فقط*، أو *نغمات ونطق معاً*. يتحكم في النغمات، وإعلانات الدخول في الطبقات، وأسماء الأوامر، ونغمات الإنجاز. *(استعلامات البيانات الحيوية مثل مساحة الأقراص، وحجم المجلدات، والهاش، ومقاييس المعالج والرام تنطق قيمتها دائماً بوضوح تام عبر كافة الأنماط)*.
* **أسلوب تأكيد إيقاف التشغيل وإعادة التشغيل:** اختر بين *حوار تأكيد (موصى به)* أو *الضغط على المفتاح مرتين خلال ثانيتين*.
* **صيغة عرض حجم الملفات والمجلدات:** اختر بين *تلقائي ذكي (موصى به)*، *بالميجابايت دائماً (MB)*، أو *بالجيجابايت دائماً (GB)*.
* **صيغة عرض سعة ومساحة الأقراص:** اختر بين *تلقائي ذكي (موصى به)*، *بالجيجابايت (GB)*، أو *بالتيرابايت (TB)*.
* **خوارزمية بصمة الملفات الافتراضية:** اختر خوارزمية البصمة المفضلة لديك بين *SHA-256 (قياسي وآمن)*، *MD5 (سريع)*، أو *SHA-1*.

  * **اكتشاف الشبكات والمقابس:** فحص ARP منخفض المستوى (`iphlpapi.dll`: `SendARP`, `GetBestRoute`, `GetIpNetTable`)، وجداول مقابس TCP/UDP الممتدة (`GetExtendedTcpTable`, `GetExtendedUdpTable`)، وقطع اتصالات TCP الفردية (`SetTcpEntry`).
  * **إدارة الخوادم المؤسسية:** واجهات Terminal Services (`wtsapi32.dll`: `WTSEnumerateSessionsW`, `WTSEnumerateProcessesW`, `WTSQuerySessionInformationW`, `WTSDisconnectSession`, `WTSLogoffSession`) و Security Account Manager (`advapi32.dll`: `LookupAccountSidW`) لتجميع استهلاك المستخدمين وكشف الـ IP للأجهزة المتصلة.
* **IEEE Standards Association:** لمواصفات IEEE 802 LAA المستخدمة في الكشف الرياضي عن عناوين MAC العشوائية للهواتف الذكية.
* **Python Open Source Community:** لتقنية مقابس UDP القابلة للتوجيه (المنسوبة إلى Christian Kauhaus) المستخدمة في اكتشاف عنوان IP المحلي دون اتصال.
* **ipify.org & maclookup.app:** لتقديم خدمات الواجهات المفتوحة المستخدمة في استخراج IP العام ومصنعي الأجهزة.
